# opotopo/seller-api-laravel

Выгрузка каталога сайта на Laravel на площадку ОПОТОПО, приём вебхуков покупок и выдача данных покупок через Seller API.

```bash
composer require opotopo/seller-api-laravel
```

Руководство — https://opotopo.com/knowledge/developers/klient-dlya-laravel
